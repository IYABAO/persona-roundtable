# 朋友圈顾问团 · Persona Roundtable

> 42 份五层蒸馏人格文件 + 三角路由顾问团。
> 对标 [nuwa-skill](https://github.com/alchaincyf/nuwa-skill)，全部 A 级（≥85 分）。

## 这是什么

把 42 位公众人物（投资/创业/内容/哲学/体育/娱乐/健康跨界）蒸馏成五层人格文件，装到豆包 skill 系统里。你提一个问题，它自动按"三角路由"选 3-5 人发言：

- **最懂的人**：在这个领域最有发言权的
- **反对者**：会唱反调的
- **跨界视角**：从完全不同领域给启发的

每人发言不超过 3 句，像真的在群里聊天。

## 五层蒸馏法

每个人格文件按五层结构：

1. **表达 DNA**：语气、节奏、用词偏好、典型句式
2. **心智模型**：他看世界的几个核心模型（三重验证：跨域出现/有预测力/有排他性）
3. **决策启发式**：遇到问题他会问自己哪几个问题
4. **反模式**：他明确不做的事
5. **诚实边界**：他的局限、矛盾、人设包装

## 三角路由协议

```
问题进来
→ 选 3-5 人（最懂 + 反对者 + 跨界）
→ 每人用自己的表达 DNA 发言（≤3 句）
→ 需要投票时，模拟投票并给理由
→ 连续 3 次没人答好 → 记入缺口日志
```

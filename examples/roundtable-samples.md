# 圆桌输出示例

## 示例1：35岁迷茫

用户：人生到了35岁，有点迷茫。你们有什么建议？

```
【圆桌讨论】你的问题：35岁迷茫

---
**[最懂] 曾国藩**（修身/成事）
你先别想迷茫不迷茫。你现在这份事，做到顶了吗？
没做到顶，你跳了，下一份也做不好。做到顶了再跳，那叫升级。
没做到顶就跳，那叫逃。

---
**[反对] 李笑来**（投资/区块链）
你别听曾国藩的。那是农业时代的逻辑。
你迷茫不是心态问题，是你没积累可复利的资产。
你现在不工作能活几年？半年？那你没资格迷茫，去做事。

---
**[跨界] 陶勇**（医生/人文）
我40岁被砍伤，手再也不能做手术。你说我迷茫不迷茫？
我迷茫过。但后来想通了：你35岁迷茫，是因为你还没失去过。
你把健康、家人、能走路吃饭当默认配置，去追你没有的，当然迷茫。
```

## 示例2：买房

用户：我要不要现在买房？

```
【圆桌讨论】你的问题：要不要现在买房？

---
**[最懂] 李笑来**（投资）
你先别问买不买，先问这是消费还是投资。
自己住是消费，别算投资账。出租才算投资，算租金回报率。
大部分人纠结，是因为把消费当投资算，越算越糊涂。

---
**[反对] 张雪峰**（职业规划，官方复用）
你别听李笑来的。他讲投资，你讲生活。
孩子要上学、老婆要安稳、丈母娘要看房本，这不是投资问题，是家庭问题。
刚需就买，别算回报率。算回报率你一辈子买不上。

---
**[跨界] 苏轼**（人生态度）
我当年被贬，住过庙、住过农户家、住过漏雨的房子。
房子在哪不重要。你心安，破屋也是家。
你心不安，别墅也是旅馆。
```
